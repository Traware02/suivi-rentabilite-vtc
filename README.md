
# Suivi de rentabilité VTC

Application web permettant de saisir chaque jour les dépenses et les gains
de chaque véhicule d'une flotte VTC (3 véhicules), puis d'exporter les données
dans un tableau Excel avec la date.

## Phase
Lab Phase (dépôt brouillon)

## Auteur(s)
- TON NOM
- NOM DU BINÔME (si applicable)

## Fonctionnalités prévues
- Saisie quotidienne des dépenses par véhicule
- Saisie quotidienne des gains par véhicule
- Historique jour par jour avec la date
- Export des données vers un tableau Excel
- Version mobile dans un second temps

## Technologies prévues
- Frontend : React
- Backend : Node.js
- Base de données : MongoDB
